# Contributing to Indigo

I'm not currently accepting outside contributions to the project.

## AI Usage Policy

I agree with [Bryan Cantrill on LLM use at Oxide Computer][oxide-llms].

[oxide-llms]: https://rfd.shared.oxide.computer/rfd/0576

I'm using AI assistance (i.e. Claude Code) to realize my vision more quickly and
with a greater degree of rigor. That said, I refuse to commit a single line of
code without reviewing and understanding it.

This is a years-long passion project. I'm fulfilled by the journey and my sense
of craftsmanship. I'm not [vibe coding] this shit.

[vibe coding]: https://twitter.com/karpathy/status/1886192184808149383
